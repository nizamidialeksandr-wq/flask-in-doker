# flask-in-doker

Пустой Flask, который запускается в Docker одной командой.

## Запуск

В Ubuntu (WSL) перейди в папку проекта и выполни:

```bash
docker compose up --build
```

Первый запуск дольше: Docker скачивает образ Python и ставит Flask внутрь контейнера.
На компьютер ставить ничего не нужно.

Открой в браузере: http://localhost:5000
Должно появиться «Привет, мир! Flask работает в контейнере.»

Вторая страница с параметром: http://localhost:5000/hello?name=Саша

Остановить: Ctrl+C в терминале, затем

```bash
docker compose down
```

## Что здесь лежит

| Файл | Зачем |
|---|---|
| `app.py` | Само приложение: два адреса, `/` и `/hello` |
| `requirements.txt` | Список зависимостей. Сейчас только Flask |
| `Dockerfile` | Как собрать образ: взять Python, поставить зависимости, положить код |
| `docker-compose.yml` | Как запустить контейнер: какой порт открыть, какую папку подключить |
| `.dockerignore` | Что не копировать внутрь образа |
| `.gitignore` | Что не коммитить в git |

## Полезное

- Правки в `app.py` подхватываются сами, пересобирать не надо: папка подключена в контейнер, а Flask запущен с `--debug`.
- Пересобирать (`--build`) нужно, только если поменялся `requirements.txt` или `Dockerfile`.
- Если порт 5000 занят, поменяй в `docker-compose.yml` левое число: `"5001:5000"`, и открывай `localhost:5001`.
- Папку проекта держи внутри Ubuntu (например, `~/projects`), а не на диске C через `/mnt/c`. С диска Windows всё работает заметно медленнее.
