# SQLite: теория перед следующим занятием

Читать заранее, ставить и настраивать ничего не нужно. Настроим вместе на занятии.

## Что такое база данных и зачем она нам

Сейчас обращения из формы ты сохраняешь в файлы в папке `messages`. Это работает, пока
записей десяток. Дальше начинаются вопросы, на которые файлы отвечают плохо:

- показать последние 10 обращений;
- найти все обращения от Ивана;
- посчитать, сколько их пришло за сегодня;
- отредактировать одно обращение и не испортить остальные.

С файлами каждый такой вопрос — это перебрать всю папку своим кодом. База данных отвечает
на них одной строчкой запроса. Хранение и поиск — её работа, а не твоя.

## Почему именно SQLite

SQLite — это база данных, которая живёт в **одном файле** рядом с проектом, например
`app.db`. Не сервис, не отдельный контейнер, не логин с паролем: библиотека внутри твоей
программы открывает файл и работает с ним.

Из этого следует важное для нас:

- В `docker-compose.yml` ничего нового добавлять не надо. Отдельного сервиса не будет.
- Файл базы лежит в папке проекта, а она уже примонтирована в контейнер через `volumes`.
  Значит база переживёт перезапуск контейнера.
- Ставить тоже ничего не нужно: модуль `sqlite3` входит в стандартную библиотеку Python,
  как `json` или `os`.

Это самая распространённая база в мире: она стоит в каждом телефоне, браузере и самолёте.
Но она не для всего: когда с данными одновременно работают много серверов и много людей,
берут PostgreSQL или MySQL. Для учебного сайта SQLite — ровно то, что нужно.

## Слова, которые встретятся в статьях

| Слово | Что значит |
|---|---|
| таблица | как лист в Excel: строки и колонки |
| строка (запись) | одно обращение из формы |
| колонка (поле) | имя, проблема, описание, адрес, дата |
| первичный ключ | номер записи, уникальный, обычно `id` |
| SQL | язык запросов к базе, на нём пишут `SELECT`, `INSERT` |
| `CREATE TABLE` | создать таблицу |
| `INSERT` | добавить строку |
| `SELECT` | прочитать строки |
| `UPDATE` / `DELETE` | изменить и удалить |
| CRUD | четыре действия выше: Create, Read, Update, Delete |
| курсор | объект в Python, через который выполняют запросы |
| коммит | подтвердить изменения, чтобы они записались в файл |

## Как это будет выглядеть у нас

Примерно так, только разберём подробно и напишем сами:

```python
import sqlite3

conn = sqlite3.connect("app.db")
conn.execute("INSERT INTO messages (name, problem) VALUES (?, ?)", (name, problem))
conn.commit()

rows = conn.execute("SELECT * FROM messages ORDER BY id DESC").fetchall()
```

Вопросительные знаки в запросе — не украшение. Так значения подставляют всегда: если
склеивать SQL строками через `+`, сайт можно сломать через обычную форму. Это называется
SQL-инъекция, на занятии покажу.
